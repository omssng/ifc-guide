Структура IFC — мини-справочник

Слева — как устроен файл на примере дома, справа — что это значит по-русски. Нажмите на любую строку.

Зелёная метка — у объекта есть свой GlobalId. Жёлтая — GlobalId нет и быть не должно.

GlobalId простыми словами

Это «паспортный номер» объекта: 22 символа, например 2O2Fr$t4X7Zf8NOew3FLOH.

  • У кого есть. У всего «самостоятельного»: проект, участок, здание, этаж, элемент (стена, плита, помещение), тип элемента, набор свойств, связь.
  • У кого нет. У «деталей» внутри объекта: отдельное свойство в наборе, материал, геометрия, координаты, сведения об авторе. Это нормально, а не ошибка.
  • Обязателен ли. По стандарту да. В криво выгруженном файле может оказаться пустым, поэтому программа не должна на этом падать.
  • Уникален ли. Должен быть уникален во всём комплекте файлов. На деле повторы бывают: скопировали элемент, размножили этаж, один и тот же объект выгрузили в два файла.
  • Не путать с номером строки. #120 в начале строки файла — это просто порядковый номер записи. Он меняется при каждой выгрузке. GlobalId остаётся тем же, пока элемент жив в модели.
  • Чей GlobalId полезен человеку. Только элемента: по нему стену можно найти в Revit, ArchiCAD, Renga или во вьюере. Набор свойств или связь по GlobalId в программе не найти.
#120 = IFCWALL('2O2Fr$t4X7Zf8NOew3FLOH', #5, 'Стена-001', $, $, #110, #115, 'Tag-77', .STANDARD.);

 │        │      └ GlobalId
 │        └ класс
 └ номер строки
